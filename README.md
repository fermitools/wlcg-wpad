# wlcg-wpad
Web Proxy Auto Discovery for the WLCG

This package is the software used for Web Proxy Auto Discovery (WPAD)
on the Worldwide LHC Computing Grid (WLCG).  It is installed on a pair
of computers each at Fermilab at CERN and gets its data from a directory
at http://wlcg-squid-monitor.cern.ch.

Documentation for this service is not up to date, but a
[paper](https://doi.org/10.1088/1742-6596/898/5/052043)
was written about the state of it in 2016. 
Other documentation is in the comments of configuration files.
